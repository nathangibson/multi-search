# Workspace Instructions

## Memory Management
- Store all memory **only in `.github/memory/`** (repository-scoped memory)
- Never create or update memory in `/memories/` (user memory) or `/memories/session/` (session memory)
- All persistent workspace knowledge must be saved to repository memory only
- After every response that creates, modifies, or deletes a file in this repo, invoke the `repo-memory` skill to update `.github/memory/`
